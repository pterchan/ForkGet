# Web 控制台

[English](console.md) · 简体中文

Compose 在 <http://127.0.0.1:8081/> 提供打包好的控制台。对于远程部署，请让控制服务继续监听回环地址，并显式转发该端口。

```sh
ssh -N -L 18081:127.0.0.1:8081 operator@your-host
```

打开 <http://127.0.0.1:18081/>。单独转发数据库前端端口，并验证其 TLS 主机名及 CA。控制服务及排空监听器不得公开暴露。控制台的 `/api/v1/` 端点使用已有的公开 API 与相同的所有者授权规则。内部 API 没有 `/api` 别名。

使用所有者 API 令牌登录。令牌仅保存在内存中，重新加载页面或退出登录时会清除，浏览器存储中不会保留令牌。选择**体验演示**才会进入演示模式。实际部署出现故障时，不会自动切换到示例数据。

1. 创建分支。分支默认只读。快照和类别允许写入时，可显式选择可写。分支异步创建。
2. 检查访问权限、存储布局、到期时间、租约版本、生命周期阶段和生效策略。这些都是独立字段。旧版 MongoDB 布局或 `mode` 的值均不能单独确定实际写入权限。临时预算授权的到期时间会与分支期限分别显示。临时授权有效时，界面会刷新生效的限制。
3. 复制连接示例，在 POSIX shell 中运行。Windows 用户可使用 WSL。在**偏好设置**中填写数据库主机、端口、前端用户名和 CA。前端密码与所有者令牌彼此独立。MongoDB 每个分支使用独立的直连客户端连接池，并禁用可重试写入。
4. 查看带类型的变更和分支范围内的审计事件。通过**导出差异**下载的 JSON 仅包含界面显示的差异。要保存并回放完整变更，请使用[结果工作流](workflow.zh-CN.md)。
5. 显式开启的语句审批策略可暂停变更操作。另一位获授权的审核者可核对不可变的分支 ID，再批准或拒绝待处理申请。默认 Agent 策略允许操作在硬性预算内执行。临时提高预算请使用单独的 `forkget budget` CLI 工作流。
6. 检查审计投递健康状况。投递待处理可能包含正常打开的事务，单独的写入暂停字段才会指示实际是否因投递受阻而暂停写入。故障仍未解决时，请参阅[审计恢复流程](audit-recovery.zh-CN.md)。
7. 检查到期和删除进度。删除会先排空会话，再清理资源。清理失败后仍可查看失败状态。要确认原生对象是否已回收，请查看清理结果，删除界面中的记录无法证明回收完成。

控制台支持英语、简体中文、繁体中文、日语、韩语、法语、德语、西班牙语和意大利语。日期使用**偏好设置**中显示的时区。SQL、对象名、ID 和 FG 错误码保留原样，整数保留 64 位精度。专门的浏览器检查覆盖键盘操作对话框、响应式导航和延迟响应。

使用独立二进制文件运行时，请在 `apps/console` 中执行 `npm ci && npm run build` 构建控制台，并在运行 `fg-control serve` 前将 `FG_CONSOLE_DIR` 设为 `build`。该变量默认未设置，此时不提供静态文件。服务账号对该目录应只有读取权限。控制台不会提供源映射、私有文件或未经打包的源代码。
