# Documentation

These guides describe **Forkget 0.0.9**, an experimental early release for
local evaluation with disposable data.

Start with [installation](install.md), then follow the
[application workflow](workflow.md). A running deployment can be used through
[native clients](connecting.md), the [CLI](cli.md) or the [Console](console.md).

Before choosing an engine or schema, read the [supported subset](support-matrix.md)
and [limitations](limitations.md). TiDB concurrent foreign-key integrity remains
blocked. Experimental availability does not establish production or managed-
environment qualification.

Operators should also read:

- [Deployment configuration and serving accounts](../deploy/README.md)
- [Source backup privileges](source-backup-roles.md)
- [Security and credentials](security.md)
- [Result retention and recovery](recovery.md)
- [Durable audit, upgrades and storage restore](audit-recovery.md)
- [Storage and permission model](architecture.md)
