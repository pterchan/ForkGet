# 安全与凭据

[English](security.md) · 简体中文

请将控制服务和连接排空服务的监听器保留在环回地址。远程所有者通过经过身份认证的 SSH 隧道访问。控制台的公开 API 别名仍要求所有者授权。代理和控制服务的内部路由不设公开别名。每套部署使用一个专用的原生服务后端，切勿将该后端指向生产源库。

所有者 API 令牌、前端数据库密码、内部令牌、原生服务账号、采集器、分支管理员和迁移账号各有不同职责，请分别管理。前端数据库用户名应与 API 所有者用户名一致。数据库密码须独立设置，切勿复用所有者令牌。独立审批与预算审查须由其他获授权的主体执行。

在数据路径的两段连接上均使用正确的 CA，验证 TLS 与主机名身份。连接失败时，请保持验证开启。设置适当的权限，保护私钥、环境文件、捕获数据和结果工件。在到期前轮换凭据和证书。控制台仅在内存中保存 API 令牌，重新加载或退出登录时会清除令牌。示例模式须显式选择。

新建分支默认拒绝写入。预算只在单个事务内统计直接涉及的行数，整个任务的用量不在该预算范围内。提交请求本身不会授予写权限。到期、策略变更或授权撤销都会使有效的事务上下文失效。被拒绝后请开启新事务。事后审批不会恢复已经回滚的操作。

响应丢失时，事务仍可能已经提交。重试变更前请先检查原生后端与审计状态。交付中断时，已知的原生操作成功结果仍可保留，此时系统会暂停受保护的新写入。系统只会自动重试交付。处理孤立的写入尝试或恢复存储时，请按[审计恢复流程](audit-recovery.zh-CN.md)操作。切勿删除审计事实或手动重建私有提交见证。

分享诊断信息前，请移除凭据、SQL 参数、应用数据和物理对象详情。审计载荷省略语句参数和文档值，但导出结果含有应用数据。请勿公开环境转储、展开后的 Compose 输出或原始后端日志。源库备份权限与服务管理权限须分开。请参阅[源库备份配置](source-backup-roles.zh-CN.md)，其中列出了普通数据 SELECT 权限以外的原生可见性和备份权限。

请通过可用的维护者渠道私下报告潜在漏洞，切勿在公开议题中包含机密信息。**Forkget v0.1.1** 是稳定版候选。生产验收和独立安全认证需要各自的证据。
